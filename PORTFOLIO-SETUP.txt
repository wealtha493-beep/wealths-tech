WEALTH'S TECH — PORTFOLIO ADMIN SETUP

FILES ADDED
- admin.html: private sign-in and project manager (open /admin.html)
- admin.js / admin.css: admin dashboard behaviour and styling
- portfolio.js: loads published projects and displays the external-site confirmation notice
- supabase-config.js: add your Supabase project URL and anon/public key here
- supabase-setup.sql: database, access rules, and image bucket setup

ONE-TIME SUPABASE SETUP
1. Open your Supabase project dashboard.
2. Go to SQL Editor, create a query, paste all of supabase-setup.sql and run it.
3. Go to Project Settings > API (or API Keys). Copy the Project URL and anon/public key.
4. Put those two values in supabase-config.js. NEVER use the service_role/secret key in browser files.
5. Go to Authentication > Users and create your own admin user with an email and a strong password. Disable public sign-ups in Authentication settings if enabled; this dashboard does not provide public registration.
6. Copy that user's UUID. In SQL Editor run this command after replacing the placeholder:
   insert into public.admin_profiles (user_id, is_admin) values ('YOUR-USER-UUID', true)
   on conflict (user_id) do update set is_admin = true;
7. Deploy the whole wealths-tech folder to the same hosting service. Keep supabase-config.js in the deployed root beside index.html.
8. Visit https://YOUR-DOMAIN/admin.html and sign in. Add projects, their https:// live URLs, descriptions and optional thumbnails.

HOW IT WORKS
- Published projects appear automatically in the Our Work section.
- Draft projects stay visible only in the admin dashboard.
- Clicking Visit website opens a notice first. Continue opens the external site in a new tab; Go back closes the notice.
- Public visitors can only read published projects. Only the admin UUID you authorise can add, edit or delete projects and upload thumbnails.

IMPORTANT
- Keep the Supabase anon/public key in the config; database security is enforced by the SQL Row Level Security policies.
- Never paste a Supabase service_role key into HTML or JavaScript.
- The project image bucket is public so thumbnail images can be displayed publicly. Do not upload private images.
- Test the admin login and add a sample project after deployment.
